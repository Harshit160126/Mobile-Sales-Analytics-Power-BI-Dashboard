# 📱 Mobile Sales Analytics Dashboard

## 📌 Project Overview

This project presents an interactive Mobile Sales Analytics Dashboard designed to analyze mobile-phone sales performance across brands, models, locations, time periods and payment methods.

The dashboard transforms transaction-level sales data into business insights that help identify revenue trends, high-performing products, geographic performance and customer purchasing patterns.

> **Disclaimer:** If the dataset is synthetic or created for portfolio purposes, the figures should not be interpreted as actual sales performance of the mobile brands represented in the dataset.

---

## 📊 Dataset

The dataset contains transaction-level mobile sales records.

Key fields may include:

- Transaction ID
- Date
- Mobile Brand
- Mobile Model
- Units Sold
- Price Per Unit
- Total Sales
- City
- Customer Age
- Customer Rating
- Payment Method

# 🔎 Business Questions Addressed

The dashboard was designed to answer questions such as:

1. What is the total sales value generated?
2. How many mobile phones were sold?
3. How many sales transactions occurred?
4. What is the average selling price?
5. Which mobile brands generate the highest sales?
6. Which mobile models perform best?
7. Which cities generate the highest sales?
8. How does sales performance change over time?
9. Which payment methods are most frequently used?
10. Which products contribute most to overall revenue?

# 🎯 Project Objective

The objective of this project was to transform raw mobile-sales transaction data into an interactive analytical dashboard that allows business users to evaluate:

- Overall sales performance
- Product performance
- Brand performance
- Geographic performance
- Sales trends
- Customer purchasing patterns
- Payment preferences

The project demonstrates the use of data analytics and visualization techniques to convert transactional sales data into business insights.
